# OpenSea

Robinhood Chain is live on OpenSea. Sherhood Sherds are ERC-721s on chain **4663**.

## One listing path

**List for sale** in Inventory or on a Sherd page posts a **Seaport** order through OpenSea’s SDK.

That same order:

- Shows on [opensea.io/collection/sherds](https://opensea.io/collection/sherds)
- Feeds **[/marketplace](/marketplace)** and prices on **[/sherds](/sherds)**

OpenSea does **not** read our old `CardMarketplace.list` contract. App list = Seaport so both stay in sync.

## Collection

[opensea.io/collection/sherds](https://opensea.io/collection/sherds)

## Open a specific Sherd

`https://opensea.io/item/robinhood/{PotCard}/{tokenId}`

## Setup

1. Connect the same wallet on OpenSea.
2. Select **Robinhood Chain**.
3. After reveal, refresh metadata on OpenSea if art looks stale.
