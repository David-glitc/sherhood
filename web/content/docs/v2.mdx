# Sherhood V2

**Coming soon.** Live pools and the app stay on today’s factory. The hardened protocol stack (factory, reveal entropy, pot lifecycle) ships as V2 — not as a mid-season cutover.

The next chapter after live pools, Trade, profiles, XP, and [$SHRH](/docs/shrh).

**Rule that does not change:** every Sherd is a real ownership claim. Distribution grows holders and creators — it does not turn Sherhood into a winner-take-all raffle.

## Form

| Layer | Job |
|-------|-----|
| **Product** | New pool / card / redeem surfaces |
| **Distribution** | How people find, invite, hold, and get rewarded for using the product |
| **Ops** | Token launch, OpenSea, sponsored create — unlocks the rest |
| **Safety** | Audit + oracle before big TVL and NAV exits |

## 2. Distribution

Distribution = attention + holdings + creator supply. Same ownership math.

### A. Holders

| Feature | What users get |
|---------|----------------|
| Hold perks | Luck + fee-free create when live |
| Loyalty seasons | Badges, flair, season boards for active holders |
| Holder drops | Occasional sealed Sherds / cosmetics / featured access (official snapshots only) |

### B. Activity

| Feature | What users get |
|---------|----------------|
| Season XP boards | Time-boxed ranks → cosmetics / early access |
| Streak campaigns | Short “keep the streak” pushes |
| Quest packs | Bundle actions (fund + list + share) → badge |

XP stays a **score**, not a token, unless a season says otherwise. [XP docs](/docs/xp).

### C. Invites

| Feature | What users get |
|---------|----------------|
| Invite links | Profile invite; XP / season progress on first fund |
| Creator invites | Deep link into a specific pool fund panel |
| Invite stats | Public invite count on profile (no wallet spam) |

### D. Creators

| Feature | What users get |
|---------|----------------|
| Creator fee share | Cut of that pool’s fee path when enabled |
| Curator spotlight | Featured pools on discovery |
| Co-create / sponsored | Brands / DAOs open pools without each wallet paying create (hold $SHRH) |

### E. Markets & liquidity

| Feature | What users get |
|---------|----------------|
| $SHRH LP programs | Official depth when token is live |
| Trade maker seasons | XP / badges for healthy list + fill |
| OpenSea + in-app | One collection story; buyers land back in product |

### F. Bridge & social

| Feature | What users get |
|---------|----------------|
| Bridge quests | First Relay → RH can count for a season |
| Multi-rail fund | ETH / WETH / USDG stay first-class |
| Telegram + share cards | Live activity + high-contrast OG for every link |
| Community grants | Small treasury grants for tools / art / education |

### G. Inventory

| Feature | What users get |
|---------|----------------|
| Event packs | Multi-Sherd packs (ownership still sums to 100%) |
| Gift / send | Transfer to profiles that allow receive |
| Offers | Bid before a formal list |

### H. Partners

| Feature | What users get |
|---------|----------------|
| Elite listings | Curated tokens for Elite pools |
| Partner pools | Labeled sponsored pools with shared promo |

### Distribution safety

- Contracts only from the app + verified channels  
- No DM “claim” links  
- No promised rarity or profit  
- Hold = connected wallet (not exchange-only)

## 3. Ship order

| # | Track | Why first |
|---|--------|-----------|
| 1 | Generative Gacha Cards | Moat + shareability |
| 2 | Distribution v1 (invites, seasons, quests) | Growth loop; TG/OG already partly live |
| 3 | Security pass + VRF docs | Before TVL scales |
| 4 | $SHRH launch + LP + holder seasons | Activates hold layer |
| 5 | Oracle / NAV | Unlocks index redeem + post-reveal exit |
| 6 | Single-card swaps + Elite | Expansion after rails exist |

Parallel is fine when items do not share the oracle dependency.

---

## 4. Out of scope

- Winner-take-all as the core product  
- Hold amounts or unofficial token addresses in docs  
- Guaranteed airdrop size, rarity, or price
